# Nora

**Nora** is the first AI coding agent purpose-built for Web3.
This repository provides a **desensitized version** of Nora's IDE — excluding the core contextual engine code — for demonstration and review purposes.

---

## Overview
Nora empowers developers to:
- Write, test, and deploy secure smart contracts end-to-end.
- Optimize for gas, scalability, and production-grade security.
- Build full dApps in hours instead of months.

---

## Note
This repo is intended for application review.
It does **not** contain Nora's proprietary contextual engine or other sensitive components.

## Supported Networks:
Nora currently supports BSC (Binance Smart Chain) and Solana for payment and transaction processing.
